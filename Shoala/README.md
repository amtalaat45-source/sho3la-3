# شعلة (Shoala)

## البناء على الكمبيوتر (Android Studio)
1. افتح المجلد في Android Studio (File > Open) وانتظر Gradle Sync.
2. Build > Build Bundle(s) / APK(s) > Build APK(s).
3. الملف: app/build/outputs/apk/debug/app-debug.apk

## البناء بدون كمبيوتر (GitHub Actions)
1. ارفع محتوى هذا المجلد كاملاً (بما فيه .github) على مستودع GitHub جديد.
2. تبويب Actions > Build APK > Run workflow.
3. بعد النجاح نزّل Shoala-debug-apk من Artifacts وفك الضغط.

## التثبيت على الموبايل
- انسخ app-debug.apk للموبايل وافتحه (اسمح بالتثبيت من مصدر غير معروف).
- أندرويد 13+: من معلومات التطبيق (App info) اختر "السماح بالإعدادات المقيدة" ثم فعّل خدمة "شعلة" من إعدادات إمكانية الوصول.
- استثنِ التطبيق من توفير البطارية.

## هيكل الصفحات
- **الرئيسية (MainActivity):** الرانك والشعلات والـ XP + زر ابدأ التركيز. أيقونة الإحصائيات فوق يمين، والإعدادات فوق شمال.
- **الإحصائيات (StatsActivity):** الرسم البياني والأرقام والجوائز.
- **الإعدادات (SettingsActivity):** إنذار الرفع، تفعيل قفل السوشيال، تغيير كارت الـ NFC.
- **التركيز (TimerActivity):** اختيار مؤقت تصاعدي أو تنازلي (مع تحديد المدة)، ثم شاشة العد.

## قفل المكان بالكاميرا (بديل الـ AR)
- من صفحة التركيز فعّل "قفل الكاميرا" واختر وضع الهاتف (الشاشة لفوق = كاميرا أمامية، لتحت = خلفية).
- عند البدء: ضع الهاتف في مكانه، اضغط "تثبيت المكان"، ابعد إيدك (3-2-1) فيسجّل بصمة صغيرة للمشهد.
- أثناء الجلسة بيقارن كل نصف ثانية؛ لو الهاتف اتشال/اتحرك/اتلف ينزل التطابق ويشتغل نفس إنذار "الهاتف اتشال".
- الشاشة بتفضل شغالة والكاميرا بتشتغل فقط وصفحة التركيز مفتوحة. لو خرجت من الصفحة يفضل الحساس شغال.
- ضبط الحساسية: ثوابت MISMATCH_BELOW / MATCH_ABOVE داخل SpotLock.kt.
